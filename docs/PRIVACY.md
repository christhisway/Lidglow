# Lidglow privacy

Lidglow is a menu-bar app that controls your MacBook's illuminated lid logo. It's built to know as little about you as possible.

- **Microphone only if you choose it.** By default Music mode listens to your Mac's own audio output through Apple's system audio tap, and Lidglow doesn't use the microphone. If you choose **Microphone** under **Settings → Music → Listen to**, macOS asks for permission, and the microphone stays on only while Music mode is running. It turns off when you switch modes, lock your Mac, let the display sleep, or close the lid, and macOS shows its microphone indicator whenever it's on.
- **Nothing is recorded.** As audio plays or the microphone hears sound, Lidglow reduces it to a single brightness level for the logo and then discards it. No audio is recorded, stored, or saved.
- **Automatic switching reads only whether an app is playing.** If you turn on **Settings → Music → Automatically switch to Music** (off by default), Lidglow asks macOS whether your chosen music apps (or, with **All apps**, any app) have audio playing. The same check is used when **Switch back after silence** is set to **Automatically**. That's a yes or no from Core Audio, with no audio attached. The audio tap starts only once Music mode is on.
- **Only connects when you check for updates.** Lidglow's only network access is **Settings → About → Check for Updates**. It runs only when you click it, never in the background or at launch. It downloads the latest stable release from GitHub Releases, as the Terminal installer does, and sends nothing about you. GitHub sees the request like any other download, including your IP address. Lidglow has no analytics, telemetry, or crash reporting. Links in Settings open in your web browser.
- **Agents send only a signal.** If you turn on **Settings → Agents** (off by default) and add Lidglow's hooks to a coding agent such as Claude Code or Codex, the agent runs `open -g` with a `lidglow://` link when it needs you, finishes, or starts working again. The link carries only the agent's name, one of those three signals, and which app the agent runs in (its bundle ID, such as `com.microsoft.VSCode`, and the agent's process ID, which Lidglow uses only to find that app), never your prompts, code, files, or project. Lidglow doesn't listen on the network for them, doesn't read the agent's data, and never edits the agent's settings itself: you paste the hooks in. Any app on your Mac can open a `lidglow://` link, so Lidglow accepts only those exact signals from the agents it knows, and the most one can do is make the logo pulse. With **Stop pulsing when I click in the agent's app** (on by default), Lidglow watches mouse clicks only while an agent is waiting, and for each click checks only which app owns the window under the pointer. It doesn't see where you clicked within it, the window's title or contents, or anything you type, and it needs no Accessibility or Screen Recording permission.
- **Settings stay on your Mac.** Your choices (the switch, mode, brightness, Music options, and agent alert options) are stored in macOS preferences (`UserDefaults`) and nowhere else.
- **Local diagnostics only.** Lidglow writes a few messages to the macOS log, for example when it takes or releases control of the logo when the audio tap or microphone input starts, or when an agent asks for attention (only its name). They contain no audio, stay on your Mac, and are only shared if you paste them into a bug report yourself.
- **You control the permissions.** macOS asks for System Audio Recording permission only when Music mode first starts, whether you choose it or it switches on automatically, and for Microphone permission only when you choose Microphone as its source. You can revoke either at any time in **System Settings → Privacy & Security**, under **Screen & System Audio Recording** or **Microphone**.
- **Your Mac's finish.** To draw the panel's preview in the right color, Lidglow reads your MacBook's finish (for example Space Black) from the system's hardware registry. It's used only for the preview.

If Lidglow ever adds another feature that needs the network, this statement will be updated before that feature ships.
